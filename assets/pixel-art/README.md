# Pixel art de RUMBO

Esta carpeta se usará para los sprites y recursos de pixel art del juego.

## Cómo usar esta lista

- `[ ]` = todavía falta crear el pixel art.
- `[x]` = pixel art terminado y guardado en esta carpeta.
- Si un objeto puede reutilizar el mismo sprite en varias habitaciones, aparece **una sola vez** o se indica que es reutilizable.
- No hace falta dibujar todavía todos estos recursos. La Etapa 1 del prólogo seguirá desarrollándose en graybox y el arte se integrará en la Etapa 2.
- Antes de producir muchos sprites fijaremos la escala oficial del pixel art.

# Recursos que NO deben repetirse innecesariamente

Cuando creemos nuevas habitaciones, primero revisar esta lista antes de dibujar un objeto nuevo.

- Puerta interior
- Ventanas, siempre que una misma variante encaje
- Marcos y fotos familiares, usando una base común cuando sea posible
- Mesa de noche
- Espejos, cuando compartan tamaño y estilo
- Escaleras, si la perspectiva permite reutilizarlas
- Plantas decorativas, salvo que queramos especies o macetas distintas

# Próximo pixel art recomendado

El primer recurso recomendado sigue siendo **Nicolás quieto mirando hacia abajo**. No es necesario crear todavía sus cuatro animaciones completas.

Cuando tengamos ese primer sprite podremos usarlo para decidir definitivamente la escala visual del resto del juego antes de producir muchos objetos.
